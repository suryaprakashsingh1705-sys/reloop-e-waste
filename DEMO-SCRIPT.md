# ReLoop — 3-minute demo outline

- **0:00–0:20 — Problem:** Explain that people often do not know how to handle unused or end-of-life electronics responsibly.
- **0:20–1:25 — Main workflow:** Add a device, show the generated recovery passport, search/filter the list, and move a record to ready for handover.
- **1:25–1:55 — Responsible disposal:** Show safe-handling tips and explain that collection details must be verified; the prototype does not book a pickup.
- **1:55–2:20 — Tracking:** Show the estimated logged-weight metric and JSON export. Explain that this is not verified waste diversion.
- **2:20–2:40 — AWS:** Show the actual AWS service/tool used and public deployment URL only after the deployment works.
- **2:40–3:00 — Impact and next steps:** State target users, what works now, and next steps for verified recycler data and shared records.
